# 四字熟語カルタ Alexa Skill

## 概要

子どもと一緒に遊ぶための、四字熟語カルタの読み上げ用Alexa Skill。

市販の四字熟語カルタを使い、Alexaが読み札の代わりに**あらかじめ用意されたシナリオを読み上げる**。

シナリオの中では答えとなる四字熟語を最後まで明かさず、最後に四字熟語を読み上げることで、子どもが該当する取り札を取る。

例えば「危機一髪」が答えの場合、

> 「太郎君が川に落ちそうになりました。あやうく大変なことになるところでした。……危機一髪！」

のように読み上げる。

つまり、Alexaが四字熟語を直接読み上げるのではなく、**完成済みのシナリオを「カルタの読み札」として読み上げる**。

## 基本的なユースケース

1. 「Alexa、四字熟語カルタを開いて」と話しかける
2. Alexaが未出題のシナリオをランダムに1つ選ぶ
3. シナリオをそのまま読み上げる
4. シナリオの最後で答えとなる四字熟語を読み上げる
5. 子どもが該当する取り札を取る
6. 「次」と話しかけると、次のシナリオを読み上げる
7. すでに出題したシナリオは、そのゲーム中は再出題しない
8. すべてのシナリオを読み終えたらゲーム終了

## 問題データ

約50個の四字熟語について、あらかじめ読み上げる文章を作成しておく。

各問題は以下の情報を持つ。

- 四字熟語
- 読み方
- 読み上げるシナリオ

シナリオはAlexa Skill側で生成・編集するのではなく、**完成済みの文章をそのまま読み上げる**。

例えば、

```json
{
  "word": "危機一髪",
  "reading": "ききいっぱつ",
  "script": "太郎君が川に落ちそうになりました。あやうく大変なことになるところでした。危機一髪！"
}
```

のようなデータとして管理する。

## 音声

Alexa標準のText-to-Speech（TTS）を利用する。

基本的には登録済みのシナリオをテキストとしてAlexaに渡し、そのまま読み上げてもらう。

必要に応じてSSMLを利用し、四字熟語を読み上げる前に少し間を入れるなど、カルタの読み手らしい演出を加える。

## 技術構成

Alexa-hosted Skillを利用し、Node.jsで実装する。

問題データはプログラム本体から分離して管理する。

```text
Skill
├── プログラム
│   └── 出題・ランダム選択・ゲーム状態管理
│
└── 問題データ
    └── 約50個の四字熟語と完成済みシナリオ
```

初期段階では外部データベースや独自サーバーは使用せず、Alexa-hosted Skill内で完結させる。

## 初期目標

まず3問程度のデータで以下の動作を確認する。

- Skillを起動できる
- シナリオをランダムに選択できる
- シナリオをAlexaが読み上げる
- 最後に四字熟語を読み上げる
- 「次」で別の問題に進める
- 同じゲーム中に同じ問題が再出題されない

動作確認後、完成済みの約50問のシナリオを登録する。
